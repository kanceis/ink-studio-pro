# Pré-visualização com dados de exemplo

Cópia do site (`site/`) com `demo-data.js`, que liga o modo de pré-visualização:
conteúdo e críticas de exemplo, marcações a fingir e pagamento desligado.
Não é o site a sério: esse lê os dados da app.

Publicada no projeto Cloudflare Pages `inkcompativel` (https://inkcompativel.pages.dev):
ramo de produção `preview-demo`, root directory `preview`, sem build.
O `wrangler.toml` desta pasta existe porque o Pages lia o da raiz (o da app) e falhava.
